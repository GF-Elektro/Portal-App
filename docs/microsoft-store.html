Microsoft Store (geplant)

Die G&F Portal EU Windows-Desktop-App ist derselbe Electron-Build wie die NSIS- und Portable-Installer auf GitHub Releases. Eine spätere Microsoft Store-Listung verpackt diesen Build (MSIX) über das Partner Center.

Berechtigungen

Das Store-Paket muss dieselben Fähigkeiten deklarieren, die die Electron-App bereits nutzt:

Capability Zweck
internetClient Laden von https://portal.gfelektro.com
microphone Diktat und Audio im Portal
webcam Baustellenfotos und Kamera
location (optional) GPS in Tagesberichten, wenn im Portal aktiviert

Lade keine Apple-Signierdateien (.p12, .p8, Provisioning Profiles) ins Microsoft Partner Center hoch.

Heute

Windows-Builds installierst du über die Download-Seite oder GitHub Releases. Kamera- und Mikrofon-Abfragen steuert die App in src/main.js (inkl. Link zu den Windows-Datenschutz-Einstellungen bei verweigertem Zugriff).
