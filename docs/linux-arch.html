Installation unter Arch

pacman-Repository und AUR

Trage dieses Repository in /etc/pacman.conf ein. Die Datenbank ist nicht signiert (SigLevel = Optional TrustAll). 

[gf-elektro]
SigLevel = Optional TrustAll
Server = https://gfe-portal-packages.web.app/arch/
sudo pacman -Sy
sudo pacman -S gfe-portal-eu

Alternativ über das AUR, sobald das Paket dort veröffentlicht ist:

yay -S gfe-portal-eu
